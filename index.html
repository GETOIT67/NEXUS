About NEXUS

VERSION 0.2.0

Your brain, connected.

A personal knowledge space for capturing ideas, keeping projects moving, and finding thoughts you forgot you had. This version runs as a single browser file.

✓ Saves to this browser using localStorage
✓ Works offline after the file is opened
✓ Export and import JSON backups
✓ Optional Supabase accounts and cloud sync

Heads up: clearing browser data can erase local notes. Export a backup now and then.

PROJECT CONNECTION

Paste your NEXUS project's Project URL and publishable key. These are browser-safe values; never use a secret or service_role key here.

YOUR ACCOUNT

Save the project connection above to enable signup and login.

NEXUS never stores your account password. Supabase Auth handles sign-in. Notes sync only after you connect an account. If email confirmation is enabled, check your inbox after signing up.
